# Historical Python prototypes

Everything in this folder is preserved from the pre-Godot implementation. It is reference material and is not imported or executed by the active game.

The active project is `../../godot_client/`. Migrated catalog data is stored there as JSON, and the developer combat demos have GDScript counterparts under `../../godot_client/scripts/dev_tools/`. This archive is retained as a read-only reference; no Python files are used by the Godot project.
