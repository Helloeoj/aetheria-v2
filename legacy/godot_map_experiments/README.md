These east-outskirts reference experiments were moved out of the active Godot project so the current layered scene is easier to find.

Archived files:
- EastOutskirtsReferenceGrid.tscn: reference image sliced into grid cells
- EastOutskirtsBlockout.tscn: older tiled blockout with rough collision shapes
- EastOutskirtsReferenceTileset.tres and build_east_outskirts_reference.gd: generator and tileset for that blockout

The current scene is godot_client/scenes/EastOutskirtsLayered.tscn. The archived scenes can be restored by moving their files back into their original folders under godot_client. Their original reference image remains in Assets/Reference.
